# 招聘网申自动填充助手

一个 Chrome（Manifest V3）浏览器扩展：在你自己的个人资料里填一次信息，之后在任何招聘网站 / 网申系统上**一键自动填充**，避免重复填写。

数据只保存在本机浏览器的 `chrome.storage.local` 中，不上传任何服务器。

## 功能

- 个人资料录入页（插件选项页）：基本信息（含身高/体重）、教育经历、获奖经历、项目经历、学生工作、实习、语言能力、论文、专利、软著、技能、自我评价，均支持多条记录。
- 三种触发方式：点击插件图标 →「一键填充」、快捷键 `Alt+Shift+F`、右键菜单「在此页面自动填充个人信息」。
- 纯本地规则匹配：通过字段的 label / placeholder / name / id / class 等做关键词识别，覆盖中英文常见字段。
- 支持 input（含 date/month）、textarea、select 下拉、radio 单选（如性别）；自动适配 React/Vue 等前端框架的表单。
- 填充完成后高亮已填充字段，方便人工核对；默认只填充空字段，可选「覆盖已填写内容」。

## 安装（加载未打包扩展）

1. 打开 Chrome / Edge，地址栏输入 `chrome://extensions`。
2. 右上角打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录（`Auto-Fill_Plugin`）。
4. 固定插件图标，右键插件图标 →「选项」，录入个人资料并保存。

## 使用

1. 打开任意招聘 / 网申表单页面。
2. 点击插件图标 →「一键填充」，或按 `Alt+Shift+F`，或右键 →「在此页面自动填充个人信息」。
3. 核对蓝色高亮的已填充字段，补充未覆盖的字段后提交。

## 目录结构

```
manifest.json                 扩展清单（MV3）
background/service-worker.js  右键菜单 + 快捷键
popup/                        一键填充弹窗
options/                      个人资料录入页
content/content.js            注入页面、监听填充指令
shared/field-dictionary.js    字段字典（核心，可扩展）
shared/matcher.js             匹配与填充引擎（核心）
```

## 已知限制与后续优化方向

- 多条记录默认只填**第一条**（教育/获奖/项目经历）；如需填多行，需先在网页上点「添加」再填充，或后续做自动添加。
- 「开始时间/结束时间/角色」等泛化字段在不同表单里可能有歧义，规则匹配无法 100% 命中，建议填充后人工核对。
- 暂不支持 checkbox 多选（如「技能多选」）和动态添加行。
- 如遇生僻、结构混乱的字段，可升级为「规则 + LLM 兜底」方案（需自行接入模型 API 或本地模型）。

## 隐私说明

- 所有资料仅存于 `chrome.storage.local`，无网络上传。
- 本版本为纯本地规则匹配，**不调用任何大模型 / 外部接口**，个人信息不会离开本机。
